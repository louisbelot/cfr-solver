# cfr-solver

Game-theory-optimal poker strategies, computed in OCaml with counterfactual
regret minimization (CFR).

- A generic interface for imperfect-information games, starting with Kuhn and Leduc poker
- CFR, CFR+, Discounted CFR and Monte Carlo CFR, with exploitability charts showing convergence
- Scaling up: abstractions, parallel solving on OCaml 5 domains, hold'em subgames
- Play against the solver in the terminal or in the browser

> Just getting started.
