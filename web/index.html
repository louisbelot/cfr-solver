CFR in the browser

The OCaml solver from cfr-solver, compiled to JavaScript with js_of_ocaml and running in a web worker on your machine. Pick a game and an algorithm, run it, then click any information set to see how its strategy and regrets moved.

Exploitability

How much a best response wins against the strategy, averaged over both seats, in the game's payoff units. Solid lines are the average strategy (the one CFR's guarantee is about), dashed lines the strategy played at that iteration. Each algorithm keeps its color; running it again on the same game replaces its line.

Run a solver first.

Every number here comes from the same code as the command-line tool: the tree walk, the regret updates and the exact best response. Checkpoints are geometric (each one 25% later than the last), and on large games older snapshots are thinned to every second one so memory stays bounded.
