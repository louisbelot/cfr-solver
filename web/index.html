CFR in the browser

The OCaml solver from cfr-solver, compiled to JavaScript with js_of_ocaml and running in a web worker on your machine. Pick a game and an algorithm, run it, then click any information set to see how its strategy and regrets moved. The river tab solves a fixed-limit hold'em river over full ranges and shows each hand class's strategy at every node.

Exploitability

How much a best response wins against the strategy, averaged over both seats, in the game's payoff units. Solid lines are the average strategy (the one CFR's guarantee is about), dashed lines the strategy played at that iteration. Running the same algorithm and sampling again on the same game replaces its line. Pause keeps the run, and Resume carries it on to the Iterations target.

Fixed-limit betting on the last street: each bet or raise is the Bet size, and bN in a path means N chips in on this street (x is check, c call, f fold). Ranges take the usual notation, for example TT+, AQs+, KQ, QJs:0.5, or random for every hand. The solver works on the public tree with one regret vector per node over all hands at once, so every iteration touches each node once.

Exploitability

Average of the two best responses as a percentage of the pot. Each algorithm keeps its line until the board, pot, bet or ranges change.

Hands at this node

Run the solver, then click a node in the public tree.

Every number here comes from the same code as the command-line tool: the tree walk, the regret updates and the exact best response. Checkpoints are geometric (each one 25% later than the last), and on large games older snapshots are thinned to every second one so memory stays bounded. Outcome and external sampling are the Monte Carlo variants of Lanctot et al. (2009); the river uses the vectorized public-tree walk.
